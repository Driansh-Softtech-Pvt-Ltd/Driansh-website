Keyboard shortcuts help you work through your inbox faster. This page lists every shortcut in the EngageOne dashboard for Mac and Windows.

## See shortcuts in the app

- Press **⌘ + /** (Mac) or **Ctrl + /** (Windows).
- Or click your avatar at the bottom of the left sidebar and choose **Keyboard shortcuts**.

On a Mac, **Option (⌥)** is the same key the app calls **Alt**.

## Moving around

| Action | Mac | Windows |
| --- | --- | --- |
| Open the command bar | ⌘ + K | Ctrl + K |
| Show all shortcuts | ⌘ + / | Ctrl + / |
| Go to the conversation dashboard | ⌥ + C | Alt + C |
| Go to contacts | ⌥ + V | Alt + V |
| Go to reports | ⌥ + R | Alt + R |
| Go to settings | ⌥ + S | Alt + S |

## Working in the conversation list

| Action | Mac | Windows |
| --- | --- | --- |
| Open the previous conversation | ⌥ + J | Alt + J |
| Open the next conversation | ⌥ + K | Alt + K |
| Switch tabs (**Mine**, **Unassigned**, **All**) | ⌥ + N | Alt + N |
| Show or hide the conversation details panel | ⌥ + O | Alt + O |
| Move up and down in a dropdown | ↑ / ↓ | ↑ / ↓ |

## Working on a conversation

| Action | Mac | Windows |
| --- | --- | --- |
| Resolve the conversation | ⌥ + E | Alt + E |
| Resolve and open the next conversation | ⌘ + ⌥ + E | Ctrl + Alt + E |
| Open the menu next to **Resolve** (**Mark as pending**, **Snooze**) | ⌥ + M | Alt + M |
| Switch to **Private Note** | ⌥ + P | Alt + P |
| Switch to **Reply** | ⌥ + L | Alt + L |
| Add an attachment | ⌘ + ⌥ + A | Ctrl + Alt + A |
| Paste an image from the clipboard into the message | ⌘ + Shift + V | Ctrl + Shift + V |

## Typing and sending

| Action | Mac | Windows |
| --- | --- | --- |
| Send the message | Enter, or ⌘ + Enter | Enter, or Ctrl + Enter |
| Insert a canned response | Type `/` | Type `/` |
| Mention a teammate in a private note | Type `@` | Type `@` |
| Close the emoji picker | Esc | Esc |

Which key sends depends on your **Hotkey to send messages** choice in **Profile settings**. If you chose **Cmd/Ctrl + Enter (⌘ + ↵)**, plain Enter adds a new line instead.

> **Tip:** On some keyboard layouts, such as German (QWERTZ), the private note and reply shortcuts also need **Shift**: **Alt + Shift + P** and **Alt + Shift + L**. The shortcuts list in the app shows the right keys for your layout.

> **Note:** Most navigation shortcuts don't fire while your cursor is in a text box. Click outside the reply box first.
